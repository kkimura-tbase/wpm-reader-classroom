# WPM Reader Classroom

WPM（Words Per Minute）を意識しながら英文を読み、読後すぐに手書きで振り返れる授業向けWebアプリです。iPadを優先し、PC・スマートフォンにも対応しています。

## 主な機能

- 英文の貼り付けとサンプル教材
- 80〜300 WPMのプリセットと数値指定
- 読了部分を単語単位で明るくする滑らかな進行表示
- 再生・一時停止・再開・最初から・10秒戻る
- 進捗率、経過時間、推定残り時間、現在WPMの表示
- ブラウザ標準SpeechSynthesisによる英語音声読み上げ
- 改行、段落、字下げを保った本文表示
- ペン、消しゴム、Undo／Redo、全消去、画像保存を備えた手書きメモ
- スタイラス専用／指でも書ける入力モード
- 教材とWPMを埋め込んだ共有リンク・QRコード
- 教材、設定、メモの端末内自動保存

## プライバシー

教材本文、WPM、手書きメモは利用者のブラウザ内に保存されます。アプリ専用のサーバーやデータベースには送信しません。

共有リンクには教材本文と設定が圧縮して含まれます。リンクを知っている人は教材を開けるため、個人情報や機密情報は入力しないでください。

音声読み上げにはブラウザ標準のSpeechSynthesisを使用します。利用できる英語音声や発音は端末・ブラウザによって異なります。

## ローカルで動かす

Node.js 22以降が必要です。

```bash
pnpm install
pnpm run dev
```

公開用ファイルを作る場合：

```bash
pnpm run build
```

## GitHub Pagesで公開する

1. このプロジェクトをGitHubのリポジトリへ送信します。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` で `GitHub Actions` を選びます。
4. `main` ブランチへ変更を送ると、自動的にビルド・公開されます。

公開URLは通常 `https://ユーザー名.github.io/リポジトリ名/` です。

## 注意事項

- 保存内容はブラウザとURLごとに分かれます。公開URLを変更しても、以前のサイトの保存データは自動移行されません。
- 長い教材では共有リンクやQRコードが大きくなることがあります。
- GitHub PagesはHTTPSで配信されるため、対応ブラウザでは音声読み上げやクリップボード機能を利用できます。
