# 自由読解：教材作成・インポート

## 使い方

1. 上部で「自由読解」を選びます。
2. 「教材をインポート」から解説付きJSONを読み込みます。配布はこのファイルを学習用の共有場所に置き、生徒がダウンロードして読み込む方式です。
3. 必要なら「教師用プレビュー・修正」で単語ごとの説明を確認・修正し、「教材を書き出す」で配布用ファイルを保存します。
4. 辞書の割合を設定して「開始」を押します。
5. 「読了・WPMを表示」で計測を止めます。解説の制限が解除され、メモはそのまま続けられます。

教師用プレビューは認証機能ではありません。自分で制限をかける自主学習向けです。計測中は設定・教師用プレビュー・モード切り替えを無効化します。

## ファイル形式

UTF-8のJSON。2MB以下、本文12,000文字・1,000語以下、タイトル80文字以下。

```json
{
  "version": 1,
  "title": "Example",
  "text": "I have finished.",
  "glosses": [
    {"index": 0, "word": "I", "lemma": "I", "pos": "代名詞", "meaning": "私は"},
    {"index": 1, "word": "have", "lemma": "have", "pos": "助動詞", "meaning": "現在完了を作る", "note": "have + 過去分詞で完了を表す。", "end": 3},
    {"index": 2, "word": "finished", "lemma": "finish", "pos": "動詞（過去分詞）", "meaning": "終えた"}
  ]
}
```

- `index`: 0始まりの単語番号。空白・句読点は数えません。
- 単語の判定：`[A-Za-z0-9]+(?:['’\-][A-Za-z0-9]+)*`
- `don't` / `well-known` は1語。ダッシュ（—）は区切り。数字も1語に数えます。
- `word`: 本文の該当単語と、大文字・小文字を含め完全一致させます。
- `lemma` / `pos` / `meaning`: 必須、各1,000文字まで。
- `note`: 任意、2,000文字まで。
- `end`: 任意。語句として強調する最後の単語の次の番号（終端を含まない）。
- 同じ綴りでも出現箇所ごとに解説を作ります。重複indexや本文と不一致のwordはインポート時に拒否します。
- 解説がない単語も登録できます。生徒には「未登録」と表示し、回数を消費しません。
- 本文だけ貼り付ける場合、既存の解説は確認後に解除されます。

## このチャットでの教材作成依頼

本文とこの形式を渡し、全単語について文脈に合った原形・品詞・短い意味を生成します。助動詞・熟語は必要な補足を付けます。完成後に教師が確認します。アプリは生成AIや外部辞書へ接続しません。

`examples/reading-sample.json` にインポートできる完全なサンプルがあります。

## 計測・辞書・保存

- 上限 = 本文の語数 × 設定割合、小数点以下は切り捨て。
- 同じ綴りを再度開いても追加消費なし。大文字小文字と直線／曲線アポストロフィは同一視します。異なる活用形は別の綴りとして数えます。
- 説明はタップ位置に対応します。同じ have でも位置によって動詞／助動詞を出し分けます。
- WPM = 本文語数 × 60 ÷ 開始から読了までの実秒数。辞書・メモ・別画面中の時間も含みます。
- 履歴は最大100件。本文・数値を保存し、同じ本文・同じ割合の前回と比較します。手書き画像を履歴へ蓄積しません。
- 自由読解の手書きメモは共通ノートです。教材の切り替えでは消しません。教材ごとに残す場合は「画像保存」を使ってください。
- ペース読解と自由読解のメモ保存領域は別です。
- 計測途中の状態・確認マークは再読み込みでは復元しません。計測中はページ離脱の警告を表示します。
- 保存先は同じURL・同じブラウザの端末内です。ブラウザのデータ削除で消えるため、教材と履歴は書き出せます。
