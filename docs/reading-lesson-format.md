# 自由読解：教材作成・インポート

## 使い方

1. 上部で「自由読解」を選びます。
2. 「教材をインポート」から解説付きJSONを読み込みます。配布はこのファイルを学習用の共有場所に置き、生徒がダウンロードして読み込む方式です。
3. 必要なら「教師用プレビュー・修正」で単語ごとの説明を確認・修正し、「教材を書き出す」で配布用ファイルを保存します。
4. 辞書の割合を設定して「開始」を押します。
5. 「読了・WPMを表示」で計測を止めます。解説の制限が解除され、メモはそのまま続けられます。

教師用プレビューは認証機能ではありません。自分で制限をかける自主学習向けです。計測中は設定・教師用プレビュー・モード切り替えを無効化します。

## ファイル形式

UTF-8のJSON。2MB以下、本文12,000文字・1,000語以下、タイトル80文字以下。

```json
{
  "version": 1,
  "title": "Example",
  "text": "I have finished.",
  "glosses": [
    {"index": 0, "word": "I", "lemma": "I", "pos": "代名詞", "meaning": "私は"},
    {"index": 1, "word": "have", "lemma": "have", "pos": "助動詞", "meaning": "現在完了を作る", "note": "have + 過去分詞で完了を表す。", "end": 3},
    {"index": 2, "word": "finished", "lemma": "finish", "pos": "動詞（過去分詞）", "meaning": "終えた"}
  ]
}
```

- `index`: 0始まりの単語番号。空白・句読点は数えません。
- 単語の判定：`[A-Za-z0-9]+(?:['’\-][A-Za-z0-9]+)*`
- `don't` / `well-known` は1語。ダッシュ（—）は区切り。数字も1語に数えます。
- `word`: 本文の該当単語と、大文字・小文字を含め完全一致させます。
- `lemma` / `pos` / `meaning`: 必須、各1,000文字まで。
- `note`: 任意、2,000文字まで。
- `end`: 任意。語句として強調する最後の単語の次の番号（終端を含まない）。
- 同じ綴りでも出現箇所ごとに解説を作ります。重複indexや本文と不一致のwordはインポート時に拒否します。
- 解説がない単語も登録できます。生徒には「未登録」と表示し、回数を消費しません。
- 本文だけ貼り付ける場合、既存の解説は確認後に解除されます。

## このチャットでの教材作成依頼

本文とこの形式を渡し、全単語について文脈に合った原形・品詞・短い意味を生成します。助動詞・熟語は必要な補足を付けます。完成後に教師が確認します。アプリは生成AIや外部辞書へ接続しません。

`examples/reading-sample.json` にインポートできる完全なサンプルがあります。

## 計測・辞書・保存

- 上限 = 本文の語数 × 設定割合、小数点以下は切り捨て。
- 同じ綴りを再度開いても追加消費なし。大文字小文字と直線／曲線アポストロフィは同一視します。異なる活用形は別の綴りとして数えます。
- 説明はタップ位置に対応します。同じ have でも位置によって動詞／助動詞を出し分けます。
- WPM = 本文語数 × 60 ÷ 開始から読了までの実秒数。辞書・メモ・別画面中の時間も含みます。
- 履歴は最大100件。本文・数値を保存し、同じ本文・同じ割合の前回と比較します。手書き画像を履歴へ蓄積しません。
- 自由読解の手書きメモは共通ノートです。教材の切り替えでは消しません。教材ごとに残す場合は「画像保存」を使ってください。
- ペース読解と自由読解のメモ保存領域は別です。
- 計測途中の状態・確認マークは再読み込みでは復元しません。計測中はページ離脱の警告を表示します。
- 保存先は同じURL・同じブラウザの端末内です。ブラウザのデータ削除で消えるため、教材と履歴は書き出せます。

## URL・QRコードでの配布

「教材と設定」の「URL・QRで配布」を押すと、教材JSONを `deflate-raw` で圧縮し base64url にして、`https://<ホスト>/<パス>/#free=<データ>` の共有URLを作ります。URLはコピーされ、QRコードも表示されます。計測中は他の設定操作と同じく無効です。

- 生徒がURL／QRを開くと自動で自由読解モードに切り替わり、教材を読み込みます。読み込み時は通常のインポートと同じ検証を行い、不正・破損・展開後200KB超のデータはエラー表示して拒否します。
- URLの上限は2,000文字です（QRの最大容量2,953バイトに余裕を持たせ、教室の画面やスマホで読み取りやすくするため）。超える場合は、公開URLで共有する方法（下記）を案内するメッセージを表示します。
- ペース読解の共有リンク（`#lesson=`）とは別形式です。
- リンクを知っている人は教材を開けます。機密情報は含めないでください。

## 公開URLでの配布（長い教材向け）

600〜700語など長い教材は、教材JSONをGitHub Pagesに置き、短いURLをQRにします。

1. 「教材を書き出す」でJSONを保存します。
2. リポジトリの `public/lessons/` に置いて（例：`public/lessons/foo.json`）mainへpushします。Pagesに自動デプロイされ、`<サイトURL>/lessons/foo.json` で公開されます。
3. 自由読解画面の「公開URLで共有」にファイル名（`foo.json`）を入力し、「共有URLとQRを作成」を押します。`<サイトURL>/?src=lessons/foo.json` 形式のURLとQRができます。

- 生徒がURL／QRを開くと自動で自由読解モードになり、JSONを取得して通常のインポートと同じ `validateLesson` で検証します。不正・取得失敗・2MB超はエラー表示します。
- セキュリティのため `src` は同一サイトの `lessons/` 配下の `.json` のみ許可します。外部URL、`..`、絶対パス、クエリ・フラグメントは拒否します。
- **公開リポジトリのため、置いた教材は誰でも閲覧できます。** 個人情報・非公開教材は置かないでください。
- 動作確認用に `public/lessons/sample.json`（`?src=lessons/sample.json`）があります。

## 共通教材と読解モード

ページは自由読解で開きます。上部の「教材ファイルを開く」で読み込んだ教材は、自由読解・ペース読解の両方に反映されます。モードの切り替えだけでは本文・教材名・単語解説は変わりません。ペース読解でも本文を編集できますが、本文を変更すると確認のうえ単語解説を解除します。

共通教材は端末内に保存し、再読み込み後も復元します。以前の保存データは、共通教材がない場合に自由読解、ペース読解の順で引き継ぎます。旧保存データは削除しません。計測中はモード変更とファイルの読み込みを無効にします。各モードの計測・手書きメモは従来どおり個別です。

辞書の上限は本文語数の 0・1・2・3・5・10・15・20% から選択でき、初期値は5%です。選択欄には実際に調べられる語数も表示します。0%は辞書なしでの読解です。小数点以下は切り捨てるため、短い本文で0語になる場合は案内を表示します。読了後は従来どおり制限を解除します。

横並びの自由読解画面では「本文とメモを左右入れ替え」で、メモを左側にも配置できます。本文とメモの幅の比率、手書き内容、読解計測を保って切り替えます。左右の設定は端末内に保存します。画面幅が狭く縦並びになる場合は、本文→メモの順に表示し、左右切り替えの操作は非表示になります。

## 黄色マーカーと本文画像

自由読解でタップした語の出現箇所に黄色（#ffeb3b）のマーカーを表示します。同じ綴りの未タップ箇所には付けません。教師用プレビューの操作は対象外です。辞書上限や解説の有無とは別に記録し、読了後のタップも追加します。同じ語を再タップして解説を閉じてもマーカーは残ります。

読了後の「マーカー付き本文を画像保存（PNG）」から、白背景・黒文字・黄色マーカーの画像をダウンロードできます。教材名とスクロール外を含む本文全体を、端末内で画像化します。メモ・操作画面・解説ポップアップは含みません。横幅を固定して折り返し、極端に長い画像は端末の画像サイズ上限に収まるよう縮小します。マーカーは再読・本文変更・教材切り替え・画面再読み込みで消えるため、その前に画像を保存してください。
