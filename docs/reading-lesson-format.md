# 自由読解：教材作成・インポート

## 使い方

1. 「教材ファイルを開く」から解説付きJSONを読み込みます。教材未読み込み時は本文を表示しません。
2. 辞書の上限をスライダーで設定し、本文タイトル右上の「開始」を押します。
3. 本文末尾右下の「読了・WPMを表示」で計測を止めます。開始前はこのボタンが無効で表示されます。
4. 読了後は解説の制限が解除され、メモ・マーカー画像保存を利用できます。

「教材の編集・保存」には教材ファイルの保存、教材名・本文の編集だけを残しています。サンプル教材への切り替え、教師用プレビュー・単語解説編集、自由読解のURL・QR作成画面は削除しました。解説の修正はJSONファイル側で行ってから読み込んでください。計測中は教材設定・モード切り替えを無効化します。

## ファイル形式

UTF-8のJSON。2MB以下、本文12,000文字・1,000語以下、タイトル80文字以下。

```json
{
  "version": 1,
  "title": "Example",
  "text": "I have finished.",
  "glosses": [
    {"index": 0, "word": "I", "lemma": "I", "pos": "代名詞", "meaning": "私は"},
    {"index": 1, "word": "have", "lemma": "have", "pos": "助動詞", "meaning": "現在完了を作る", "note": "have + 過去分詞で完了を表す。", "end": 3},
    {"index": 2, "word": "finished", "lemma": "finish", "pos": "動詞（過去分詞）", "meaning": "終えた"}
  ]
}
```

- `index`: 0始まりの単語番号。空白・句読点は数えません。
- 単語の判定：`[A-Za-z0-9]+(?:['’\-][A-Za-z0-9]+)*`
- `don't` / `well-known` は1語。ダッシュ（—）は区切り。数字も1語に数えます。
- `word`: 本文の該当単語と、大文字・小文字を含め完全一致させます。
- `lemma` / `pos` / `meaning`: 必須、各1,000文字まで。
- `note`: 任意、2,000文字まで。
- `end`: 任意。語句として強調する最後の単語の次の番号（終端を含まない）。
- 同じ綴りでも出現箇所ごとに解説を作ります。重複indexや本文と不一致のwordはインポート時に拒否します。
- 解説がない単語も登録できます。生徒には「未登録」と表示し、回数を消費しません。
- 本文だけ貼り付ける場合、既存の解説は確認後に解除されます。

## このチャットでの教材作成依頼

本文とこの形式を渡し、全単語について文脈に合った原形・品詞・短い意味を生成します。助動詞・熟語は必要な補足を付けます。完成後に教師が確認します。アプリは生成AIや外部辞書へ接続しません。

`examples/reading-sample.json` にインポートできる完全なサンプルがあります。

## 計測・辞書・保存

- 上限 = 本文の語数 × 設定割合、小数点以下は切り捨て。
- 同じ綴りを再度開いても追加消費なし。大文字小文字と直線／曲線アポストロフィは同一視します。異なる活用形は別の綴りとして数えます。
- 説明はタップ位置に対応します。同じ have でも位置によって動詞／助動詞を出し分けます。
- WPM = 本文語数 × 60 ÷ 計測中の実秒数。計測中の辞書・メモの利用時間を含み、一時停止中の時間を除きます。
- 履歴は最大100件。本文・数値を保存し、同じ本文・同じ割合の前回と比較します。手書き画像を履歴へ蓄積しません。
- 自由読解の手書きメモは共通ノートです。教材の切り替えでは消しません。教材ごとに残す場合は「画像保存」を使ってください。
- ペース読解と自由読解のメモ保存領域は別です。
- 両モードの「一時停止」で、経過時間と読解位置を同じブラウザに保存します。自由読解ではタップした語・辞書の残り回数・確認マークも保存します。再読み込みすると保存した状態に戻り、「再開」で続きから計測できます。計測中に画面を離れたときも一時停止します。
- 保存先は同じURL・同じブラウザの端末内です。ブラウザのデータ削除で消えるため、教材と履歴は書き出せます。

## 以前の共有リンク

以前作成した共有リンク（#free=、#lesson=、?src=）の読み込みは互換性のため残しています。自由読解から新しい共有URL・QRを作る画面はありません。教材配布はJSONファイルを使用します。

## 共通教材と読解モード

ページは直近に保存した中断中のモードで開きます。中断中の読解がなければ自由読解で開きます。上部の「教材ファイルを開く」で読み込んだ教材は、自由読解・ペース読解の両方に反映されます。モードの切り替えだけでは本文・教材名・単語解説は変わりません。ペース読解でも本文を編集できますが、本文を変更すると確認のうえ単語解説を解除します。

共通教材は端末内に保存し、再読み込み後も復元します。以前の保存データは、共通教材がない場合に自由読解、ペース読解の順で引き継ぎます。旧保存データは削除しません。計測中はモード変更とファイルの読み込みを無効にします。各モードの計測・手書きメモは従来どおり個別です。

辞書の上限は本文語数の 0・1・2・3・5・10・15・20% から選択でき、初期値は5%です。スライダーの目盛りは 0・1・2・3・5・10・15・20% で、実際に調べられる語数も表示します。0%は辞書なしでの読解です。小数点以下は切り捨てるため、短い本文で0語になる場合は案内を表示します。読了後は従来どおり制限を解除します。

横並びの自由読解画面では「左右を入れ替え」で、メモを左側にも配置できます。本文とメモの幅の比率、手書き内容、読解計測を保って切り替えます。左右の設定は端末内に保存します。画面幅が狭く縦並びになる場合は、本文→メモの順に表示し、左右切り替えの操作は非表示になります。

## 黄色マーカーと本文画像

自由読解でタップした語の出現箇所に黄色（#ffeb3b）のマーカーを表示します。同じ綴りの未タップ箇所には付けません。辞書上限や解説の有無とは別に記録し、読了後のタップも追加します。同じ語を再タップして解説を閉じてもマーカーは残ります。

読了後の「マーカー付き本文を画像保存（PNG）」から、白背景・黒文字・黄色マーカーの画像をダウンロードできます。教材名とスクロール外を含む本文全体を、端末内で画像化します。メモ・操作画面・解説ポップアップは含みません。横幅を固定して折り返し、極端に長い画像は端末の画像サイズ上限に収まるよう縮小します。読了後のマーカーは、再読・本文変更・教材切り替え・再読み込みの前に画像で保存してください。

## 読解画面の操作

本文タイトル右上の「開始」で計測を開始します。開始時は設定欄を閉じて本文の先頭に移動します。本文の末尾右下に「読了・WPMを表示」を置き、読了後は同じ場所にWPM、前回との比較、マーカー付きPNGの保存、再読の操作を表示します。本文のヘッダーには計測状態・経過時間・辞書の残り語数をまとめて表示します。

両モードの常設の操作説明や重複表示を減らし、選択状態・短い操作名・ボタンの配置で操作を示します。エラー、保存場所、共有範囲、利用できない機能など判断に必要な案内は残します。ペース読解では目標スピードと開始ボタンを先に表示し、本文の編集は「本文を編集」を開いて行います。

辞書上限を設定欄の先頭に置き、教材名・本文の編集とファイル保存は「教材の編集・保存」にまとめています。再読でマーカーを消す場合は画像保存済みか確認します。単語一覧からの選択では該当箇所まで移動して解説を開きます。

## 誤タップの取り消し

単語の解説欄で「このタップを取り消す」を押すと、その出現箇所の黄色マーカーと「あとで確認」の印を解除します。計測中、その綴りを別の箇所で調べていなければ消費した1語分を戻します。同じ綴りを他の箇所で調べている場合や、上限到達で意味を表示できなかった場合は残り語数を増やしません。読了後の取り消しは画像のマーカーに反映し、確定済みの計測記録は変えません。

## スピードとリセット

ペース読解の目標スピードは40〜500 WPMを10 WPM刻みのスライダーで選べます。数値入力では1 WPM刻みで指定でき、その場合はスライダーが最も近い10刻みの位置を示します。

両モードの右上に「リセット」を表示します。自由読解では確認後に計測、辞書の上限（5%）、左右配置と比率（本文60：メモ40）、黄色マーカー、手書きメモとその操作履歴を初期化します。読み込んだ教材・単語解説と読書記録は残ります。ペース読解では従来どおり計測、速度（160 WPM）、手書きメモなどを初期化し、教材は残します。他方のモードのメモは削除しません。

## 手書きメモの移動・保存

メモは縮小中も表示範囲全体に書けます。「移動」やスクロールで右や下へ進むと、書ける範囲が広がります。新しい書き込みは線の座標として保存するため、拡大・縮小や再読み込みで元の線を描き直します。以前のメモ画像も表示します。

「画像保存」で手書きした範囲の画像を開きます。iPadでは「写真に保存」を押し、共有メニューから「画像を保存」を選びます。共有メニューに保存先が表示されない場合は、プレビュー画像を長押ししてください。PNGのダウンロードも選べます。
